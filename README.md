## 📂 Featured Projects

### 🔍 [Qdrant Search System](https://github.com/amine823/QdrantDocs-gpt)

A high-performance hybrid search and RAG-based question answering system powered by vector databases and advanced retrieval techniques. The project combines modern AI retrieval strategies with a responsive frontend to deliver fast, context-aware search over documents.

**Tech:** Python, Qdrant, Groq API, FastAPI, React, TypeScript, Vite, Chakra UI, Zustand, Docker.

**Features:**
- ⚡ Hybrid search pipeline combining dense + sparse strategies
- 🧠 Retrieval-Augmented Generation (RAG) for contextual answers
- 📊 Reciprocal Rank Fusion (RRF) for improved result ranking
- 🎯 ColBERT-based reranking for higher precision results
- 🧩 HNSW indexing for fast approximate nearest neighbor search
- 🌐 Full-stack architecture with FastAPI backend and React frontend
- 📦 Dockerized deployment for both local and cloud environments
- 🖥️ Modern, responsive UI built with TypeScript and Chakra UI
